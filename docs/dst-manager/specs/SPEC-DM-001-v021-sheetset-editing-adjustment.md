# DST Manager v0.21 图纸集编辑需求调整规范

## 背景

v0.21 的测试与业务复核表明，图纸集编辑应收敛为以子集标题、图号范围和受控插入为核心的流程。本文定义该版本的行为、输入契约、校验和验收要求；它替代 [DST Manager MVP 架构基线](../architecture/ARCH-DM-001-dst-manager-mvp-baseline.md) 中与本规范冲突的编辑能力描述，但不改变其 DST/XML 受控修改、CAD Worker、永久快照及可恢复整批发布要求。

## 范围

本规范包括：

- 图纸集与图纸自定义属性定义的新增、删除、CSV 导入导出；
- 新建子集及其独立 DWG；
- 通过指定位置批量插入图纸；
- 子集标题、图号范围和图纸标题/后缀的统一派生；
- 旧编辑能力的移除及相应的预览、校验和测试。

本规范不包括任意 XML 编辑、空子集、跨子集移动图纸、手工调整既有子集顺序，或手工编辑图纸标题。

## 行为

### 统一派生

所有结构性变更完成后，系统必须基于最终子集顺序和各子集内最终图纸顺序，一次性派生所有受影响的图号、子集图号范围、子集显示名、图纸标题、后缀、DWG 文件名、布局名和 DST 路径引用。Web、API 和 CAD Worker 不得分别实现这些派生规则。

子集显示名由不可编辑的图号范围和可编辑标题组成，格式为 `<图号范围> <标题>`。图号范围由该子集的图纸图号动态计算；标题修改后，该子集全部图纸的基础标题必须同步为该标题。

图纸标题不得手工编辑。基础标题等于所属子集标题；需要后缀时，后缀前固定保留一个半角空格。

### 图纸标题后缀

`.env` 使用以下配置：

| 变量 | 合法值 | 默认值 | 含义 |
| --- | --- | --- | --- |
| `EnableAddNumberSuffix` | `true`、`false` | `true` | 是否追加图纸标题序号后缀 |
| `NumberSuffixType` | `1`、`2` | `1` | `1` 为汉字序号，`2` 为数字序号 |

配置缺失时使用默认值；值不在合法集合内时，服务启动诊断必须报错。汉字序号沿用 `legacy/Function.ps1` 中 `Transdigit` 的编号语义。

按去除图号范围后的子集标题分组。每组子集按图号范围起始图号排序；组内图纸按子集顺序和子集内图纸顺序连续编号。一个分组仅有一张图纸时不追加后缀。启用后缀时示例为 `燃气管道平面图 (一)` 或 `燃气管道平面图 (1)`；关闭时仅保留基础标题。

### 自定义属性

系统必须支持图纸集（`sheetset`）和图纸（`sheet`）自定义属性定义的新增、删除、导出与导入。

- 属性名称先去除首尾空白，再按不区分大小写规则判重；AutoCAD 已存在 `go` 时，新增 `Go` 必须报错。
- 新增 `sheetset` 属性时，在图纸集上写入其默认值；新增 `sheet` 属性时，必须以默认值同步写入全部现有图纸，保证所有图纸具有一致的属性集合和值。
- 删除 `sheet` 属性时，必须从全部图纸移除该属性值；删除 `sheetset` 属性时，从图纸集移除该属性值。
- 既有的属性值编辑能力仅可修改已定义属性的值，不得借此创建名称不一致的属性定义。

### CSV 导入导出

CSV 必须采用 UTF-8 编码、逗号分隔，且只包含以下三列及固定表头：

```csv
type,name,default_value
```

`type` 只能是 `sheetset` 或 `sheet`；`name` 不可为空；`default_value` 可为空。模板下载返回上述空表头。导入在预览阶段校验编码、分隔符、表头、列数、必填值、类型和名称重复，不合规则阻断执行。

导入采用幂等合并：同名且同类型的现有属性跳过；同名但类型不同阻断并报告冲突；CSV 中未列出的既有属性保持不变。新属性按默认值创建，并遵循本规范的全量图纸同步规则。导出以同一格式输出当前属性定义。

### 插入图纸

插入图纸必须指定目标子集、该子集内序号、`向前添加`或`向后添加`以及数量；方向默认 `向后添加`。子集已有图纸时，序号范围为 `[1, 当前图纸数]`。批量插入的图纸必须在同一指定位置连续插入，标题由子集标题自动派生，不接受手工标题。

新图纸仍必须提供可验证的布局来源，并进入现有的 CAD 暂存、重建、Handle 回读和发布流程。

### 插入子集

插入子集必须指定图纸集内子集序号、`向前添加`或`向后添加`、初始图纸数，以及一个模板 DWG/DWT 和其中一个布局。方向默认 `向后添加`，初始图纸数默认 `1` 且不得小于 `1`。所有初始图纸复制同一个已选模板布局，并创建该子集独有的 DWG。

已有子集时，插入序号范围为 `[1, 当前子集数]`；图纸集没有子集时允许以序号 `1` 创建首个子集。系统不允许生成或保留空子集与空 DWG。插入位置会导致后续子集顺序更新，但不提供对既有子集的独立排序操作。

## 接口

接口层应以受控命令表达本规范中的属性维护、CSV 预览/执行、插入图纸、插入子集与子集标题修改。所有写操作必须提交 `base_revision_id`，并保留现有的“预览 → 明确确认 → 执行”顺序。

预览至少展示：属性新增/删除和受影响图纸数、CSV 行级错误、插入前后顺序、图号范围变化、标题及后缀变化、待创建/重建的 DWG 和布局。不得提供可绕过预览、CAD Worker 或发布器的直接写入接口。

移除跨子集移动图纸、调整子集顺序和修改图纸标题的命令、API 与 Web 入口；不得仅在界面隐藏而保留可调用端点。

## 数据

属性定义至少包含 `type`、规范化后的 `name` 和 `default_value`。名称比较保留原始显示大小写的同时，必须维护不区分大小写的唯一性约束。

子集需区分可编辑标题与派生图号范围；图纸标题是派生值。后缀配置由运行配置读取，不作为用户任意输入写入 DST。所有派生结果均属于变更计划和修订记录的一部分，以支持审阅与恢复。

## 异常

以下情况必须在预览或计划阶段阻断，并给出可定位的错误：非法序号或数量、空子集、缺少或不可读的模板/布局、CSV 编码或结构错误、非法 `type`、属性名为空或大小写冲突、同名不同类型、派生名称冲突、危险 DWG 路径或布局名、基准修订变化和文件锁。

CAD 执行、Handle 回读、结构校验或发布失败时，继续适用现有的失败即不发布或整批回滚语义。

## 安全边界

本规范不改变以下安全约束：DST 只能经 `DST → XML DOM → DST` 修改；未知 XML 结构必须保留；用户输入不得拼接为 SCR、Shell 命令或未校验路径；所有正式写入必须经过永久 before 快照、暂存校验、发布日志和可恢复整批事务；服务仅监听 `127.0.0.1`。

只读打开不得因标题规范化、属性校验或配置读取而修改 DST/DWG、创建 `.dst-manager/` 或更新时间戳。既有项目的标题仅在发生结构性写入时按本规范重新派生。

## 兼容性

本文替代 `ARCH-DM-001` 中“支持同一子集内移动图纸、跨子集移动图纸、修改子集顺序和手工修改图纸标题”的编辑能力。该架构基线的发布安全、DOM 兼容、路径解析、双 AutoCAD 版本和 Worker 边界继续有效。

实施前必须新增 ADR，记录上述编辑能力由自由操作模型转为受控插入和派生模型的决策及其替代关系。

## 测试

- 单元测试：同名子集跨子集连续编号、两种后缀、关闭后缀、单图纸不加后缀、范围/标题联动、批量插入、首次创建子集、空子集拒绝、属性默认值同步及大小写冲突。
- 集成测试：CSV 模板、UTF-8/逗号/三列表头校验、必填字段、类型校验、重复属性、同名不同类型冲突、幂等导入、导出及基准修订保护。
- API 与 Web 测试：不存在旧操作入口；覆盖属性维护、CSV 导入导出、新建子集、批量插图和预览显示。
- CAD 系统测试：AutoCAD 2016 与 2020 均验证从模板创建独立 DWG、批量布局复制、重建后布局顺序及 Handle 回读。
- 回归测试：确认只读打开不写入，且任意 CAD 或发布故障后正式目录保持整批旧版本或完整新版本。

# Dst Manager v0.21 需求调整
## 增加需求
- 增加图纸集自定义属性的增加和删除功能
- 增加图纸自定义属性的增加和删除功能，注意整个图纸集中的所有图纸的自定义属性要保持一致，增加或删除要同步更新
- 增加图纸集和图纸自定义属性的导入导出csv的功能：
  - csv文件要包含`type`、`name`、`default_value`三列，其中`default_value`可以为空，其他都不能为空，`type`决定自定义属性类别，只能为`sheetset`或`sheet`
  - 提供csv模板下载，导入要校验csv格式，类型是否正确
  - csv采用utf-8编码，分隔符为逗号
- 增加创建子集（新建dwg文件）功能
- 增加为图纸标题自动增加序号后缀的功能：
  - 后缀类型有两种：
    - 括号包裹的汉字序号：例如：`(一)`,汉字编号逻辑参考[Function.ps1](legacy/Function.ps1)中的`Transdigit`函数
    - 括号包裹的数字序号：例如：`(1)`
  - 如果子集只有1张图纸，不增加序号后缀
  - 支持是否启用该功能，默认启用，设置在`.env`文件中，变量名`EnableAddNumberSuffix`，取值为`true`或`false`，默认值为`true`
  - 后缀类型在`.env`文件中设置，变量名`NumberSuffixType`，取值为`1`或`2`，默认值为`1`，`1`表示汉字序号，`2`表示数字序号

## 修改需求
- 取消图纸在子集间移动的功能
- 取消子集顺序调整的功能
- 取消修改图纸标题的功能，因为图纸标题（不含序号后缀）要与子集标题（不含图号范围前缀）一致，比如子集名称为`4-5 燃气管道平面图`，该子集的所有图纸标题都是`燃气管道平面图 (*)`
- 子集名称修改重做：
  - 子集名称分为`图号范围`和`标题`两部分，`图号范围`不可手动编辑,`标题`可以手动编辑。比如`4-5 燃气管道保护平面图`,`4-5`不可手动编辑，`燃气管道保护平面图`可以手动编辑
  - 图号范围根据图纸情况动态计算，比如原为`4-5`,增加2张图纸后，图号范围变为为`4-7`
  - 子集标题修改后，所有图纸标题（不含序号后缀）要同步更新
- 新增图纸重做：
  - 输入图号改为输入序号，输入要做校验，范围为[1,待增加图纸子集的图纸数量]
  - 增加`向前添加`或`向后添加`的选项，表示在输入序号位置前或位置后添加新图纸，默认`向后添加`
  - 标题不可手动编辑，要根据子集标题动态计算
  - 支持一次增加多张图纸

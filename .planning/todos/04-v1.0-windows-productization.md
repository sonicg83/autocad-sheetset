# 阶段 4：v1.0 Windows 产品化

状态：待实施  
建议周期：1～2 周，另加真实项目试用期  
前置条件：阶段 1～3 全部验收。  
阶段目标：提供可安装、可升级、可诊断、可长期维护的 Windows 单人应用。

## 1. 成功标准

- 用户通过一个入口启动应用，不需要分别打开 API 和 Worker 终端。
- 应用启动时自动完成配置、数据库版本、端口、AutoCAD 和遗留任务检查。
- 升级失败不会破坏应用数据库或工程文件。
- 修订、任务和缓存具有明确保留策略，清理前可预览且不删除唯一恢复副本。
- AutoCAD 2016/2020 的完整真实项目验收通过。

## 2. 工作包

### P4-01 单入口进程主管

- [ ] 提供一个启动命令或 Windows 启动器，管理 API、浏览器和 CAD Worker 生命周期。
- [ ] 保留 API 与 CAD Worker 进程隔离，不把 AutoCAD 执行放回 Web 请求进程。
- [ ] 防止重复启动同一数据目录实例；检测端口冲突并给出可操作提示。
- [ ] Worker 崩溃后由主管限次重启，正在执行的任务交给阶段 1 恢复协议处理。
- [ ] 应用退出时停止接受新任务，等待或明确中止当前任务。
- [ ] 提供无需自动打开浏览器的维护模式和 CLI 模式。

### P4-02 首次运行与设置

- [ ] 首次运行向导检查数据目录、AutoCAD 2016/2020、插件和默认并发数。
- [ ] 设置页面可修改默认 CAD 版本、超时和最大并发，保存前校验范围。
- [ ] 展示应用、Python、数据库 schema、前端和插件版本。
- [ ] 配置变化不影响正在执行的任务；任务保存提交时的能力快照。

### P4-03 安装、升级与数据库迁移

- [ ] 确定 Windows 分发方式和目录布局，禁止依赖开发仓库路径。
- [ ] 插件按 AutoCAD 版本打包，并在启动时验证构建标识。
- [ ] 升级前备份应用 SQLite；迁移失败时恢复备份并阻止启动写任务。
- [ ] 保留命令行诊断与手工迁移入口。
- [ ] 建立从最后一个 v0.x 版本升级到 v1.0 的自动化测试。
- [ ] 提供简体中文安装、升级、备份和卸载说明。

### P4-04 保留与清理策略

- [ ] 分别统计永久修订、任务暂存、日志、模板缓存和应用数据库占用。
- [ ] 永久 before 快照默认不自动删除。
- [ ] 仅自动清理已成功归档任务的可重建临时文件，并设置安全时间窗口。
- [ ] 手工清理先展示文件、大小、关联修订和可恢复性。
- [ ] 禁止清理仍被修订 manifest 引用的唯一文件。
- [ ] 清理操作写入应用审计日志。

### P4-05 发布前完整验收

- [ ] 小型、黄金工程和至少一个日常真实工程副本完成全流程。
- [ ] AutoCAD 2016/2020 均覆盖元数据修改、插入、删除、排序、跨子集移动、删除最后一张图纸和最大布局组。
- [ ] 多 DWG 并发 1/2/4 对比，确定 v1.0 默认并发值。
- [ ] 覆盖文件锁、磁盘不足、CAD 超时、插件加载失败、发布中断和启动恢复。
- [ ] 覆盖历史恢复、恢复后的再次编辑及应用升级。
- [ ] 连续真实使用观察期内不出现不可恢复的数据损坏或任务状态丢失。

## 3. 重点修改入口

- `src/dst_manager/interfaces/cli.py`：统一启动、维护和诊断命令。
- 新增进程主管模块：API/Worker 生命周期与退出协调。
- `src/dst_manager/config.py`：安装后目录、版本化配置和范围校验。
- `scripts/`：构建、打包、安装和升级验证。
- `plugins/`：双版本插件可复现构建和版本标识。
- `docs/`：用户手册、故障恢复和发布说明。

## 4. 测试矩阵

- [ ] 重复启动、端口占用、Worker 崩溃、主管退出和系统重启。
- [ ] 空数据库、旧数据库、迁移失败和备份恢复。
- [ ] 安装路径含中文、空格和 OneDrive 的运行测试。
- [ ] 清理候选、被引用文件保护和清理中断恢复。
- [ ] 安装包或分发目录的敏感信息、私有样本和构建产物检查。
- [ ] 全套 Ruff、pytest、Alembic、Web、Playwright、插件构建和双版本 CAD 测试。

## 5. v1.0 发布门槛

- [ ] 所有阶段验收项完成，无未解释的 P0/P1 数据安全问题。
- [ ] 安装、首次运行、打开项目、编辑、发布、恢复和升级均有用户文档。
- [ ] 默认只监听 `127.0.0.1`，没有登录或远程访问入口。
- [ ] 公开发布内容不包含 `legacy/`、`lagacy/`、`sample/`、凭据、客户路径或插件构建输出。
- [ ] 双版本真实 CAD 验收结果和已知限制已记录。
- [ ] 完成至少一个真实项目副本的连续试用并关闭阻断问题。

## 6. 风险与回退

- v1.0 不以支持更多 AutoCAD 版本为目标，优先保证 2016/2020 的可重复运行。
- 进程主管只负责本机生命周期，不扩大为 Windows 服务或远程执行平台。
- 若安装打包延迟，可先交付固定目录的便携版，但必须保留升级和数据库备份机制。

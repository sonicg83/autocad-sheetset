# 阶段 3：v0.4 单人工作流

状态：待实施  
建议周期：2 周  
前置条件：阶段 2 的类型化编辑器和草稿模型已稳定。  
阶段目标：减少重复输入和环境排查，让一个用户能够长期管理多个本地项目、模板和历史任务。

## 1. 成功标准

- 常用项目第二次打开时无需重新输入 DST 路径、根目录或默认 CAD 版本。
- 模板可以登记、重新检查、发现变更并直接选择布局。
- 发布前能运行项目健康检查并定位问题对象。
- 用户可以用 CSV 批量审阅和准备修改，但 DST 领域模型仍是最终事实来源。
- 遇到问题时可导出结构化、脱敏的诊断包。

## 2. 工作包

### W3-01 最近项目与工作区设置

- [ ] 最近打开项目列表、收藏、移除记录和重新定位。
- [ ] 每个工作区保存默认 CAD 版本、根目录覆盖和最近模板。
- [ ] 检测 DST 被移动、删除或外部修改，并提供重新定位或只读打开。
- [ ] 修订和任务列表默认按当前工作区筛选。
- [ ] 应用设置与项目业务文件分离，复制项目后仍可重新建立绑定。

### W3-02 模板库

- [ ] 复用 `templates` 表，保存路径、SHA-256、CAD 版本、布局清单和检查时间。
- [ ] 支持添加、重新检查、停用和删除模板记录。
- [ ] 模板哈希变化后禁止沿用旧检查结果。
- [ ] 插入图纸时从模板库选择布局，不要求手工输入绝对路径和布局名。
- [ ] 明确 DWG/DWT、AutoCAD 版本和布局兼容诊断。

### W3-03 项目健康检查

- [ ] 检查缺失、歧义和越界 DWG 路径。
- [ ] 检查重复图号、布局名、AcSm ID 和 Handle。
- [ ] 检查无引用 DWG、DST 外部变化、模板变化和文件锁。
- [ ] 检查磁盘空间、应用数据库可写性和发布日志恢复状态。
- [ ] 结果按错误、警告、信息分类，并可定位到对象或文件。
- [ ] 只读健康检查不得修改工程文件或更新时间戳。

### W3-04 CSV 交换

- [ ] 导出稳定列定义：对象 ID、子集、图号、标题、布局、DWG 和允许编辑的自定义属性。
- [ ] 导入先生成语义差异和诊断，不直接写 DST。
- [ ] 使用稳定对象 ID 匹配；缺失 ID 时不得仅凭模糊名称自动合并。
- [ ] 明确新增、删除和移动操作的显式字段与确认规则。
- [ ] 处理 UTF-8 BOM、Excel 打开兼容和重复行。
- [ ] CSV 只是批量输入方式，最终仍转换为类型化命令并经过完整预览。

### W3-05 诊断包和维护工具

- [ ] 导出应用版本、配置摘要、CAD 能力、任务时间线、执行计划和日志。
- [ ] 自动隐藏 API Key、令牌及不必要的个人路径段。
- [ ] 增加应用数据占用统计、孤立任务目录和失效模板检查。
- [ ] 清理操作只生成候选预览；正式删除留到阶段 4 的保留策略实现。

## 3. 重点修改入口

- `src/dst_manager/infrastructure/persistence/`：最近项目、模板和设置持久化。
- `src/dst_manager/application/`：健康检查、CSV 差异和诊断包编排。
- `src/dst_manager/interfaces/api.py`：项目、模板、健康检查和 CSV API。
- `web/src/`：开始页、模板库、健康检查和导入预览。
- `migrations/`：模板和设置字段迁移。

## 4. 测试矩阵

- [ ] 移动、删除、外部修改项目后的最近项目行为。
- [ ] 模板哈希变化、布局变化和 CAD 版本不匹配。
- [ ] 健康检查严格只读测试，包括文件时间戳不变。
- [ ] CSV 往返、重复 ID、未知 ID、非法编码和字段冲突。
- [ ] 诊断包脱敏测试，防止环境变量和凭据进入归档。
- [ ] Playwright 覆盖最近项目、模板选择、健康检查和 CSV 预览。

## 5. 阶段验收

- [ ] 常用工作区可从开始页一键打开。
- [ ] 新增图纸可直接从已验证模板库选择来源布局。
- [ ] 健康检查能在发布前发现路径、重复项和环境问题。
- [ ] CSV 修改必须经过差异预览和正常任务发布链路。
- [ ] 诊断包通过敏感信息扫描。
- [ ] Ruff、pytest、Web 构建、Playwright 和相关 CAD 测试全部通过。

## 6. 风险与回退

- 最近项目保存的是定位信息，不得把本地绝对路径写入公开测试夹具或日志样例。
- CSV 不得成为第二套业务规则；所有数据必须进入统一命令和规划层。
- 模板变化时宁可要求重新检查，也不能根据旧布局缓存继续执行。
